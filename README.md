# 🤖 AI GitHub Career Advisor

An AI-powered GitHub profile analyzer built with **Python** and the **GitHub REST API**.

This project fetches GitHub user information and provides intelligent career recommendations by analyzing profile details such as followers, repositories, bio, company, and location.

---

## 🚀 Features

- Search any public GitHub user
- Fetch profile data using the GitHub REST API
- Display:
  - Username
  - Followers
  - Public Repositories
  - Bio
  - Company
  - Location
  - Account Creation Date
- AI-style profile analysis
- Career recommendations based on GitHub activity
- Error handling for invalid usernames
- Clean and beginner-friendly Python code

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ai-github-career-advisor.git
```

Install dependencies:

```bash
pip install requests
```

Run the project:

```bash
python main.py
```
